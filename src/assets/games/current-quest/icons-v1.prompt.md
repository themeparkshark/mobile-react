# Current Quest icon sheet

Generated for `icons-v1.png` with the built-in image generator. Reference images: the actual iPhone 16 Current Quest render, the app's original Theme Park Shark mascot artwork, and the illustrated Ocean Memory Match card sheet. Prompt: Create a transparent 3-by-1 sprite sheet with equal square cells. Cell 1 is a luminous ivory pearl with a small gold sparkle. Cell 2 is a friendly slate-blue rock and coral cluster. Cell 3 is an open golden treasure chest with blue trim and a few coins. Match the source app's playful, crisp, outlined 2D illustration style, saturated blue and gold palette, soft shading, and readable small-size silhouettes. No lettering, UI, borders, backgrounds, or extra objects. Keep each object centered in its own cell with transparent margins.

The sheet is bundled locally so the queue game works without a network connection.
