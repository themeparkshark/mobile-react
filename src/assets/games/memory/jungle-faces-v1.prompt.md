# Jungle Cruise memory deck art

Generated as original Theme Park Shark game art on September 24, 2026. The existing `pirates-faces-v1.png` and `pirates-extra-faces-v1.png` sheets were layout and style references. No Disney artwork or characters were supplied as references.

- `jungle-faces-v1.png`: 4 by 2 card grid with a skipper logbook, canopied river boat, compass, gorilla, elephant, waterfall, tropical leaf, and original safari-hat shark mascot.
- `jungle-extra-faces-v1.png`: 2 by 1 card grid with a hippo and tiger.

Both sheets preserve the 1536 by 1024 pixel cell grid and the established blue, navy, gold, and orange frame. They are used by the original `jungle` Memory Match deck in `src/games/memory/decks.ts`.
